# Restaurant Cards Website

A modern, responsive restaurant showcase website featuring 5 dining establishments in New Jersey.

## Features

- **5 Restaurant Cards** with sliding image galleries
- **Auto-playing sliders** (4-second intervals)
- **Interactive navigation** with arrows and dots
- **Touch swipe support** for mobile devices
- **Keyboard navigation** (left/right arrow keys)
- **Fully responsive** design for all screen sizes
- **Beautiful animations** and smooth transitions

## Restaurants Featured

1. **The Gourmet Kitchen** - Italian Fine Dining (Hoboken, NJ)
2. **The Velvet Lounge** - Cocktails & Wine Bar (Jersey City, NJ)
3. **Sakura Sushi House** - Japanese Cuisine (Fort Lee, NJ)
4. **Urban Bean Cafe** - Coffee & Pastries (Princeton, NJ)
5. **Spice Garden Family Kitchen** - Indian Kid-Friendly (Edison, NJ)

## Files

- `index.html` - Main HTML page with all 5 restaurant cards
- `resturant.htm` - Copy of index.html
- `styles.css` - Complete styling with responsive design
- `script.js` - JavaScript for sliders and interactions

## How to Run

### Option 1: Open Directly in Browser
1. Navigate to this folder
2. Double-click `index.html`
3. Or drag and drop `index.html` into your browser

### Option 2: Using Python Server
```bash
cd restaurant-website
python3 -m http.server 8080
```
Then open your browser to: `http://localhost:8080`

### Option 3: Using File Path
Open your browser and press Ctrl+O (or Cmd+O on Mac), then navigate to:
```
/home/user/Function.js/restaurant-website/index.html
```
